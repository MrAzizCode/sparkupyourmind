# SparkUpYourMind

A responsive, sketchbook-inspired creative wellbeing storefront. The reset studio offers short prompts without sign-in or data collection. The three-product collection supports search, sorting, product details, and a cart saved in the browser. Checkout is a preview only; no order is placed and no payment is collected.

## Pages

- Home page: `index.html`
- Products page: `products.html`

## Edit Products

Products are stored in the `products` array inside `script.js`. Update the product name, description, details, price, image, or featured status there.
