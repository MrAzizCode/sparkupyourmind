# SparkUpYourMind

A simple responsive website about creativity, creative burnout, and products that help creatives prevent, manage, and recover from burnout.

## Pages

- Home page: `index.html`
- Products page: `products.html`

## Edit Products

Products are stored in the `products` array inside `script.js`. Update the product name, description, details, price, image, or featured status there.

## Publish With GitHub Pages

1. Create a new public GitHub repository named `sparkupyourmind`.
2. Upload all files from this folder to the repository root.
3. In GitHub, open `Settings > Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select branch `main` and folder `/root`.
6. Save.

GitHub will publish the website at:

`https://YOUR-GITHUB-USERNAME.github.io/sparkupyourmind/`
